# Privacy policy

*Last updated: 24 November 2026*

Artboard is a private, personal project with one user, its owner. This page explains what it does with Google user data.

## What it accesses

With the owner's permission, Artboard has **read-only** access to Google Drive (`drive.readonly`). It lists and downloads image files in the folders its owner has chosen. It never changes, moves, deletes or shares anything in Google Drive, and it doesn't read the owner's email, contacts or any other Google data.

## What it does with it

- Images are copied to a server on the owner's home network and shown on picture-frame screens in that home.
- Google user data is never sold, used for advertising, or shared with anyone else, and it's used only to provide Artboard's own features.

## Storage and deletion

The sign-in that lets Artboard read Drive is kept in the macOS Keychain on the owner's computer. Access can be revoked at any time from the Google Account's security settings (Third-party apps with account access).
