# Artboard

Artboard is a private, personal project that curates artwork and shows it on picture-frame screens in one home.

It reads images from Google Drive folders that its owner has chosen, with read-only access, and copies them to a small server on the home's own network, where they're prepared and shown on the frames. It is not offered to the public, and has one user: its owner.
